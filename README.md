# Geography Quiz Helper

## Purpose / Problem Solved
Assists users with geography study questions and automated quiz evaluations by leveraging large language models to deliver structured answers and explanations.

## Key Nodes & Configuration
* **Trigger 1:** Captures user quiz inputs or prompt requests.
* **AI LLM 2:** Processes queries through the language model to generate contextually accurate geography answers.
* **Display 3:** Formats and outputs structured response text for quick review.

## Impact & Results
Successfully implements its intended query-response loop, consistently delivering fast, automated answers for educational review.
